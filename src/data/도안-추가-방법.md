# 도안 추가 방법

도안을 계속 늘려 나가실 수 있도록, 새 도안을 넣을 때 손대야 할 곳을 한 파일로 제한해 두었습니다.

## 1. patterns.ts 에 한 덩어리만 추가

`src/data/patterns.ts` 의 `SOURCES` 배열에 아래 형식으로 덧붙이면 끝입니다.

```ts
{ id: 'rabbit', title: '토끼', category: 'animal',
  rows: ['..W..W..', '..W..W..', '.WWWWWW.', 'WKWWWWKW', 'WWWWWWWW', 'WWWPPWWW', '.WWWWWW.', '..W..W..'] },
```

- `id` 는 다른 도안과 겹치지 않는 영문 소문자
- `category` 는 `animal | vehicle | food | shape | nature` 중 하나
- `rows` 는 행 개수와 한 행의 글자 수가 같아야 합니다 (6, 8, 10, 12 중 하나)

필요 비즈 수, 색상 수, 난이도(쉬워요·보통이에요·도전해요)는 `derivePattern` 이 자동으로 계산하므로 직접 적지 않습니다. 난이도 기준은 색상 수이며 3색 이하는 쉬워요, 4~6색은 보통이에요, 7색 이상은 도전해요입니다.

## 2. 사용할 수 있는 색 글자

보유 재고 12색만 사용합니다. 재고에 없는 색을 쓰면 차감 계산이 어긋납니다.

| 글자 | 색 이름 | 글자 | 색 이름 |
|---|---|---|---|
| A | 연두 | S | 살색 |
| G | 초록 | W | 화이트 |
| K | 검정 | V | 연보라 |
| R | 빨강 | P | 찐핑 |
| O | 주황 | T | 투명 |
| Y | 노랑 | N | 연한 갈색 |
| . | 빈칸 (비즈를 놓지 않는 자리) | | |

## 3. 확인

개발 중에 `validatePatterns()` 를 호출하면 행 길이가 어긋난 도안을 잡아냅니다.

```ts
import { validatePatterns } from './data/patterns';
console.log(validatePatterns()); // 빈 배열이면 정상
```

## 4. 새 색상을 들여온 경우

`src/data/inventory.ts` 의 `BEAD_COLORS` 에 `{ key, name, hex, init }` 한 줄을 추가하고, `ColorKey` 타입(`src/types/pattern.ts`)에 글자를 더하면 재고 화면·차감표·도안 렌더링에 함께 반영됩니다.
